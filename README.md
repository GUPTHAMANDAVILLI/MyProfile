## ABOUT

I am a Computer Science and Engineering graduate focused on building reliable software, testing complex systems, and understanding how applications behave from both an engineering and security perspective.

My technical foundation spans **full-stack development, quality assurance, cybersecurity, backend engineering, databases, cloud fundamentals, and AI-powered applications**. I enjoy turning concepts into working systems and breaking applications intentionally to identify defects before users do.

My current development path combines **Angular, TypeScript, Node.js, PostgreSQL, REST APIs, Git, Linux, Docker fundamentals, and secure application practices**, while continuing to strengthen my understanding of software architecture and production engineering.
